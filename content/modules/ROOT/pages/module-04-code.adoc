= Game Time

Now that your AI assistant is wired up, it's time to get your hands dirty - by building a simple game using the AI chat's help. In this module, you're not solving a business-critical problem... yet! You're exploring, experimenting, and building confidence with AI-assisted coding through something fun: a simple game.

== Choose a Game to Build

Pick **one** of the following lightweight game projects, available in both Python and Bash:

. **Rock Paper Scissors**: Play rock, paper, scissors against the computer!
. **Word Scramble**: The program scrambles a word and the user has to guess what it is.
. **Simple Quiz Game**: The program asks a few trivia questions and then gives a final score.

You only need to pick one - but feel free to try more if you have time.

=== Understanding the Starter File Structure

Each game starter file is organized into **two sections** (all as comments):

1. **🎯 Initial Prompt Section** - A high level goal for the model to accomplish

2. **💡 Enhancement Ideas Section** - Suggestions for features you can ask the AI to add once your basic game is working

And a marker to let the agent know where to put the code it will be generating.

=== How to Use the Starter Files

Follow this workflow:

**Step 1: Read the entire file**

Open your chosen game file and read through all the commented instructions to understand what you'll be asking the model to build.

**Step 2: Generate your first version**

With the file open, at the bottom of the right hand window click the `+` icon next to the file name and say "Implement this game from scratch in this file only." The Nemotron model will generate working code for you.

**If you see errors:**

* **"command not found" or "permission denied"**: Double-check the filename is spelled correctly and ensure you're in the correct directory (use `ls` to list files).
* **Other errors**: Copy the error message and paste it into the AI chat - ask "I got this error, can you help me fix it?" The AI can help you debug!

**Step 5 (Optional): Enhance your game**

Once your basic game is working, you can make it better! This step is optional but fun.

Look at the enhancement ideas in the comment sections of your starter file. Use the AI assistance techniques below to add features, improve code quality, or experiment with new ideas.

== Using AI Assistance for Enhancement

If you want to enhance your game, here's how to use your AI assistant effectively to iterate and improve your code.

Open the AI chat panel in VS Code (focus the cursor in the editor then press `Ctrl+Alt+I` on Linux or `Cmd+Ctrl+I` on Mac).
